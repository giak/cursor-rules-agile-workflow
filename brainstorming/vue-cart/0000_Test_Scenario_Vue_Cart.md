# Test Scénario : Utilisation de 0000 pour Créer une Règle Vue Cart

## Objectif

Ce document trace l'application de la méta-règle `0000-cursor-rules.mdc` (version 3.1, post-consolidation et avec manifeste) pour créer une nouvelle règle spécifique : `2101-vue3-shopping-cart-scaffold.mdc`. Cette nouvelle règle aura pour but de guider la génération d'un projet Vue 3 simple avec une fonctionnalité de panier d'achat.

L'objectif est de tester en pratique :

- Le workflow complet de `0000` (évaluation de complexité, adaptation de stratégie, création écosystème, validation).
- La clarté et l'efficacité des instructions de la méta-règle.
- L'interprétation par le LLM des différentes étapes.
- La viabilité de l'approche adaptative S/M/C.

Ce scénario servira de base pour la création de la documentation améliorée (Cookbook / Scénarios).

## Contexte Initial

- Règle `0000` mise à jour (Consolidation KB, Manifeste).
- Choix de l'Option B : utiliser `0000` pour créer une _autre_ règle.
- Projet cible : Un scaffold Vue 3 (utilisant `npm create vue@latest` avec options par défaut + `vue-router`) avec des composants basiques pour afficher des produits et un panier simple (pas de logique backend, données statiques initialement).
